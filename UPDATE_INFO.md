# FestManager 6.1.0 — Alpha Assistente Comercial

Base: 5.7.0 (alphafest-manager-main22)

## Entrega
- Nova aba **🤖 Alpha**.
- Análise assistida e local das mensagens dos clientes, sem depender de API paga.
- Identificação de produto, tema, ocasião, idade, cores, quantidade, prazo e detalhes.
- Checklist de perguntas faltantes por família de produto.
- Resposta sugerida editável antes do envio.
- Busca automática de projetos semelhantes e produtos do catálogo.
- Transferência dos dados para a Jornada ou Projeto Personalizado sem redigitação.
- Nenhuma resposta é enviada automaticamente.
- Nenhuma migração destrutiva e nenhum arquivo de dados incluído no pacote de atualização.
